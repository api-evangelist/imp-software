# IMP Software

> IMP Software builds MAT-first financial management software for the UK education sector. Its flagship product, IMP Planner, is a single-database, trust-wide platform for budgeting, forecasting, reporting, Integrated Curriculum Financial Planning (ICFP) and purchasing used by Multi-Academy Trusts (MATs) and their schools. The company is based in Exeter, UK and is trusted by 550+ trusts across roughly 6,000 schools. In September 2025 it secured a growth investment from Partech.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public IMP Software website. IMP Software does not publish a public developer API, OpenAPI specification, SDKs or MCP server; IMP Planner is a closed SaaS application accessed by trust finance teams.
